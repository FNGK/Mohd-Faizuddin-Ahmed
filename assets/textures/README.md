# Hero globe — land mask

`earth-land.png` is the land mask the hero globe (`assets/js/hero-globe.js`)
samples to place dots on continents (the dotted-Earth). It is loaded at
runtime; if it is missing or fails, the globe falls back to an even sphere.

**The current file is a ROUGH PLACEHOLDER** (approximate continent shapes,
generated by hand) so the feature is visible. Replace it with a real map for
precise continents/coastlines.

## Replacing it with a precise map

Drop a better image in at this exact path (`assets/textures/earth-land.png`),
matching this spec:

- **Projection:** equirectangular (plate carrée), **2:1** aspect ratio
  (e.g. 2048×1024, 1024×512 — it is downsampled to 512×256 at runtime).
- **Content:** a **land/ocean mask** — **land = bright/white, ocean = dark or
  transparent**. A high-contrast silhouette works best. (A photographic
  "blue marble" earth also works but gives softer edges; a clean land mask is
  sharper.)
- Search terms: "equirectangular world land mask png", "world land silhouette
  equirectangular". Natural Earth raster land masks are ideal and public
  domain.

The globe keeps a dot only where the mask is land (alpha ≥ 40 and brightness
≥ 90), so getting those two conventions right (light land, dark/transparent
ocean) is all that matters. No code change needed — refresh and it upgrades.

Note: a dotted globe renders **coastlines/continents** precisely, but it
cannot draw thin **country border lines** (dots can't resolve 1px borders).
Country-level line detail would need a textured-sphere approach instead.
